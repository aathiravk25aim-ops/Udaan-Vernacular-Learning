Udaan Offline Lesson Audio

The lesson recordings in public/audio/lessons are bundled with the offline app.
Each seeded lesson has:
  /lessons/<lesson-id>/hi.mp3  - Hindi
  /lessons/<lesson-id>/ta.mp3  - Tamil

English continues to use the existing browser audio path.
For teacher-created lessons that do not have a bundled recording, the app falls
back to the device speech engine.
